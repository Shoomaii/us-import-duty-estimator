# US Import Duty & Full Landed Cost Estimator audit — November 25, 2026

This report covers the November 25 changes through [commit f124462](https://github.com/Shoomaii/us-import-duty-estimator/commit/f12446280507161a22862be1fbb6fccc28e4624e).

## Findings

- **High · The calculator applies the wrong fiscal-year fees.** It uses $32.71 and $634.62 as the minimum and maximum formal merchandise processing fee and $2.62 for an automated informal entry. Effective October 1, 2026, the corresponding FY2027 figures are $34.58, $670.86, and $2.77. The engine and sales copy repeat the outdated figures. Version these amounts by entry date and test the effective-date boundary against the official schedule. [Engine](https://github.com/Shoomaii/us-import-duty-estimator/blob/f12446280507161a22862be1fbb6fccc28e4624e/src/duty_engine.mjs#L6-L12) · [Federal Register, Table 2](https://www.govinfo.gov/content/pkg/FR-2026-07-31/html/2026-15530.htm)
- **High · The latest hardening commit incorrectly maps Hong Kong origin to China for Section 301.** A $1,000 Hong Kong-origin USB cable shipment using the built-in preset produced $250 of Section 301 duty. The cited executive order changes marking requirements. CBP distinguishes goods genuinely originating in Hong Kong for Section 301. Preserve the origin code and evaluate each tariff program independently. The current unit test explicitly expects the incorrect mapping. [Origin mapping](https://github.com/Shoomaii/us-import-duty-estimator/blob/f12446280507161a22862be1fbb6fccc28e4624e/src/duty_engine.mjs#L95-L102) · [Regression test](https://github.com/Shoomaii/us-import-duty-estimator/blob/f12446280507161a22862be1fbb6fccc28e4624e/tests/duty.test.mjs#L99) · [CBP Section 301 FAQ](https://www.cbp.gov/trade/programs-administration/entry-summary/section-301-trade-remedies/faqs)
- **High · Unrecognized tariff codes can produce exportable zero-duty estimates.** I supplied a $1,000 Vietnamese SKU with an unrecognized HTS code and no manual duty rate. The Pro engine returned zero base duty, no validation errors, and enabled export. Require an exact supported classification or a user-confirmed manual rate. The six-digit prefix fallback also needs explicit confirmation when it substitutes a different tariff line. [Classification lookup](https://github.com/Shoomaii/us-import-duty-estimator/blob/f12446280507161a22862be1fbb6fccc28e4624e/src/duty_engine.mjs#L80-L92) · [Zero-rate fallback](https://github.com/Shoomaii/us-import-duty-estimator/blob/f12446280507161a22862be1fbb6fccc28e4624e/src/duty_engine.mjs#L159-L169)
- **Medium · A valid large batch can fail during rounding.** In a consolidated entry of 400 separate $1 Vietnamese cotton-shirt SKUs, rounding the first 399 fee shares individually left a negative fee for the final row. The engine threw “MPF override must be a valid non-negative number.” Distribute integer cents so every allocation is nonnegative and reconciles to the entry fee. [Allocation](https://github.com/Shoomaii/us-import-duty-estimator/blob/f12446280507161a22862be1fbb6fccc28e4624e/src/duty_engine.mjs#L548-L567)
- **Commercial · The $19 purchase button leads to the public repository.** Its destination tells the seller to upload the finished Pro HTML. The same public repo already contains that complete downloadable product. Connect the customer button to checkout and decide how the paid file should be distributed before advertising it as a paid unlock. [Purchase button](https://github.com/Shoomaii/us-import-duty-estimator/blob/f12446280507161a22862be1fbb6fccc28e4624e/scripts/build.mjs#L329-L331) · [Release instructions](https://github.com/Shoomaii/us-import-duty-estimator/blob/f12446280507161a22862be1fbb6fccc28e4624e/README.md#L21-L22)

All eight checked-in tests passed. Both generated HTML files matched the checked-in builds byte-for-byte. Additional runs reproduced the Hong Kong surcharge, the exportable zero-duty estimate for an unknown code, and the batch rounding error. Storefront fulfillment remains unverified.
